## Reflexión final


El uso de Git y GitHub facilita enormemente la organización y el control de versiones en cualquier tipo de proyecto, permitiendo trabajar de manera ordenada, registrar cada cambio y colaborar eficientemente mediante herramientas como ramas, issues y pull requests.
