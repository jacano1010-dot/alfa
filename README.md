
# Proyecto: Servicio Digital de Mensura y Gestión de Terrenos

## Descripción

Este proyecto consiste en una plataforma digital informativa orientada a un servicio profesional de mensura. Documenta los procesos técnicos de agrimensura, el relevamiento topográfico de parcelas, la confección de planos de mensura, trámites catastrales y la asesoría legal-técnica sobre límites de propiedades y deslindes.

## Objetivo

Organizar, documentar y estructurar un repositorio digital utilizando Git y GitHub, aplicando un flujo de trabajo profesional con ramas, commits ordenados, gestión de issues y pull requests para un sistema vinculado a servicios de mensura y catastro.

## Estructura del repositorio

* `README.md`: Explicación general, alcance y objetivos del proyecto.
* `ENTREGA.md`: Registro oficial del proceso de trabajo, comandos utilizados y enlaces de interés.
* `proyecto/`: Carpeta que contiene los archivos principales de la web.
  * `index.html`: Página principal con la información del servicio de mensura.
  * `styles.css`: Hoja de estilos para el diseño visual de la interfaz.
